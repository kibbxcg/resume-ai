# 产品需求文档

## 1. 这个产品给谁用？
- 求职者：想让自己的简历更有竞争力
- 面试官：想更深入了解候选人

## 2. 解决什么问题？
传统简历是静态的，面试官看完就完了。
这个产品让简历变成"能对话的"，面试官可以追问细节。

## 3. 核心流程是什么？
用户注册 → AI 对话采集信息 → 上传简历补充 → 
生成知识库 → 选择模板生成网站 → 发布获得链接 → 
面试官访问链接和 AI 对话

## 4. MVP 必须有什么？（P0）
- [ ] AI 对话采集（至少支持文字问答）
- [ ] PDF 上传解析
- [ ] 知识库生成（向量化）
- [ ] 生成 1 套模板的网站
- [ ] 面试官免登录问答
- [ ] 用户注册/登录

## 5. MVP 不做什么？（先砍掉）
- 多语言
- 多套模板
- 自定义域名
- 付费功能
- 移动端 App
