# 📋 MVP 需求文档 (Requirements)

> **文档定位**：本项目是求职者 AI 分身工具，同时也是求职者技术能力的**体验式证明**。
> **核心原则**：面试官通过流畅、精准、安全的对话体验，自然感知到求职者的全栈工程与 AI 落地能力。
> **运行模式**：求职者自带 API Key + Serverless 代理；面试官零配置直接使用。

## 2. 功能边界 (MVP Scope)

### ✅ IN SCOPE (v1.0 必须实现)
- **安全代理**：Next.js Route Handler 透传 LLM 请求，服务端读取环境变量中的 API Key。
- **配置驱动**：YAML 个人资料解析 + Zod 运行时 Schema 校验。
- **RAG-lite 引擎**：System Prompt 动态注入 Profile Context，Token 预算控制在 4K 以内。
- **流式交互**：基于 SSE 的流式对话 UI，支持 Markdown 渲染与代码高亮。
- **安全护栏**：内置 Prompt 注入防护与超范围问题拒答逻辑。
- **一键部署**：提供 Vercel Deploy Button，适配 Edge Runtime。
- **移动端适配**：响应式布局 + 触摸优化 + 虚拟键盘防遮挡。

### ❌ OUT OF SCOPE (v1.0 明确不做)
- 访客端 API Key 输入框 / 密钥管理界面
- 用户账号系统 / 注册登录流程
- 数据库 / 对话历史云端持久化存储
- 多模态交互（语音、视频、文件上传）
- 管理后台 / 数据分析看板
- 服务端缓存 / 会话状态管理

## 3. 关键技术约束（体验驱动）

> ⚠️ 以下约束的目标是让面试官在**使用过程中自然感知到技术力**，而非依赖源码审查。

- **密钥安全**：API Key 严禁出现在客户端代码、构建产物或响应头中；所有 LLM 调用必须经由服务端 API Route 代理。（面试官可通过 DevTools 验证安全性）
- **性能基线**：Lighthouse Performance ≥ 90；Edge Function 冷启动 < 800ms；首句响应延迟 < 1.5s。（面试官体感"秒回"）
- **类型安全**：全程 TypeScript `strict: true`；所有外部输入经 Zod 校验。（保障运行时稳定，避免面试官遇到报错白屏）
- **隐私合规**：对话历史仅存于面试官浏览器 Session Storage，刷新即焚；不收集任何访客指纹或 IP。（可在页面底部声明，增强信任感）
- **错误体验**：网络异常、Key 无效、模型限流等场景必须有友好的用户提示，而非空白或原始报错。（体现工程成熟度）

## 5. 术语表

- **RAG-lite**：轻量级检索增强生成，本项目中指将 YAML 全量注入 System Prompt 而非使用向量数据库。
- **Guardrails**：安全护栏，限制 AI 输出范围的 Prompt 工程策略。
- **Edge Runtime**：Vercel/Cloudflare 等平台的边缘计算环境，冷启动远快于传统 Node.js Serverless。
- **SSE**：Server-Sent Events，用于实现 LLM 流式输出的轻量级协议。
